# Ayra Bakers

A modern, responsive bakery website built with React and Vite. Showcasing Ayra Bakers' delicious cakes, pastries, and bakery products.

## Features

- **Home Page**: Welcome and overview of bakery offerings
- **About Us**: Information about Ayra Bakers
- **Speciality Cakes**: Showcase of premium cakes for various occasions
- **Our Products**: Complete product catalog including cakes, pastries, cookies, and more

## Technologies Used

- **React 19**: Modern React with hooks and functional components
- **Vite**: Fast build tool and development server
- **React Router**: Client-side routing with HashRouter
- **Bootstrap 5**: Responsive design and components
- **React Bootstrap**: React components for Bootstrap

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AnuPrem2005/Ayra-Bakers.git
   cd Ayra-Bakers
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
